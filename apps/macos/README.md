# AI 信迹 Mac

这是 AI 信迹的原生 SwiftUI Mac 客户端，不是 Electron 或 WebView 套壳。

## 当前版本

- `0.01`：第一版原生客户端
- `0.02`：文件时间线按日期分组、图片预览、收藏同步、复制链接、网页录入入口
- `0.03`：窗口可拖动、补齐收藏/信源/待办入口、恢复线上本地附件预览
- `0.05`：详情栏可拖拽/收起、原生文本录入、剪贴板读取与待办识别
- `0.06`：详情收起后时间线全宽展开、卡片/按钮悬浮动效、顶部双击缩放、原生录入支持文件上传
- `0.08`：信源与时间线合并、单击卡片打开详情、分栏宽度记忆、可更换头像，并接入完整待办增删改查
- `0.09`：补齐项目菜单、录入项目选择、标签入口、收藏置顶/预览、设置页、滴答清单同步和更可靠的小手悬浮光标
- `0.10`：强化全局小手悬浮、按钮/卡片阴影动效、顺滑分栏拖拽，并将项目页改为高密度列表
- `0.11`：小手悬浮改为整块区域命中，并用 AppKit 原生鼠标事件重做时间线/收藏分栏拖拽
- `0.12`：加宽分栏命中区域，使用 AppKit deltaX 拖拽，并修复整块 hover 只在文字上触发的问题
- `0.13`：重排录入页，剪贴板监听收为顶部小按钮；补齐 Markdown 工具栏、Enter 提交、Shift+Enter 换行、粘贴截图进附件、项目关联提交与更明显的 hover 阴影
- `0.14`：在 0.13 基础上加入 Enter 空内容/重复提交保护，并作为本轮最终可打开版本
- `0.15`：重做时间线/收藏分栏拖拽，改为细线短柄、拖动不再触发窗口移动，并修复粘贴截图重复添加附件
- `0.16`：应用菜单加入“重启 AI 信迹”和快捷键 Control + Command + R，方便调试时快速重启
- `0.17`：调试版登录态改为本地保存，避免反复弹钥匙串授权；同时修复分栏拖动被窗口移动抢走的问题

后续每次打包都使用新的版本号输出独立 `.app` 和 `.dmg`，不会覆盖旧包。

## 功能

- 邮箱密码登录 Supabase
- Keychain 保存登录状态
- 文件时间线列表
- 时间线搜索：文件名、标签、来源、摘要、OCR、文档抽取内容
- 文件详情：AI 摘要、来源描述、自动标签、OCR / 抽取文本
- 用 Bearer Token 下载附件并调用 macOS 打开
- 图片缩略图预览
- 收藏同步
- 收藏置顶、取消收藏、打开网页详情
- 项目菜单、项目搜索、新建项目、录入时关联项目
- 待办筛选、优先级调整、同步/批量同步滴答清单
- 设置页：AI、Notion、滴答清单、flomo、OCR、邮件收录、OSS
- 复制附件链接
- 原生录入文本、剪贴板内容和本地文件
- 打包生成可双击打开的 `.app` 和 `.dmg`

## 打包

在仓库根目录有 `.env.local` 时，脚本会读取 `NEXT_PUBLIC_SUPABASE_URL` 和 `NEXT_PUBLIC_SUPABASE_ANON_KEY` 并写入 App 的 `Info.plist`。

```bash
cd apps/macos
./scripts/package-app.sh
```

指定下一个版本：

```bash
APP_VERSION=0.17 ./scripts/package-app.sh
```

输出：

- `apps/macos/dist/AI 信迹 0.17.app`
- `apps/macos/dist/AI 信迹-0.17.dmg`
